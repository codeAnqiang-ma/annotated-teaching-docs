# 借鉴

## 取景

- **GitHub Docs**：图要让人知道元素在屏上哪儿；只够上下文，不是整块桌面。禁止变暗、禁止光标、禁止信息只出现在图上。深橙描边 `#BC4C00`。
- **Tango / Scribe**：整页/整窗 + 点击处高亮；步骤句在图下，不压 UI。
- **ScreenSteps**：箭头 / 序号 / 图上字 / 模糊都做成对照。单图序号 ≤ 4，必须对正文。
- **ScreenGuide / Snagit**：箭头从空白指向目标；步骤条叠顶；打码前后。
- **Azure / 阿里云 / 企微**：整窗编号认路，说明在图下或正文。
- **华为云 / 腾讯云**：红框 +「单击红框内」。爱裁弹窗。
- **PixPin / Snipaste / 少数派**：放大镜、图上短中文、对错对照、统一一种框色。
- **Apple**：认工具栏用引线短标签，不是圆点。

原页样图：`examples/scenes/refs/en/`、`refs/zh/`、`refs/scenes/`。清单见各目录 `MANIFEST.txt` / `NOTES.txt`。

## 只借规则、不抄外观

- guidewright：live rect，视口截，不要事后猜像素。
- app-docs：等数据；一步说清楚。
- app-screenshots：选择器先测，失败停。

不借：特写裁切当默认、大红圆角当默认、五色虚线、图内长句当默认、聚光把整页吃黑。

# 整窗标注

读者必须先认出「这是哪个界面」，再看见要点。所以默认交**整窗**，编号贴在控件上。不要把控件单独裁成一张小图。

样张：`examples/scenes/看效果.md`（我们画的十五种 + `refs/en` `refs/zh` `refs/scenes` 原页）。

## 网上两派

| 派 | 谁 | 图怎么做 | 说明写哪 |
|---|---|---|---|
| 官方文档 | GitHub Docs、Cloudflare、DigitalOcean、Stripe | 干净、少标、留够四周认路 | 正文必须能离开图读懂。GitHub 禁止变暗、禁止光标、禁止图上独占长句 |
| SOP / 录屏 | Tango、Scribe、Snagit、ScreenSteps | 整窗 + 框 / 箭头 / 编号 / 引线 | 步骤句可贴图下。ScreenSteps：单图序号 ≤ 4，必须对正文列表 |

中文帮助（阿里云、华为云、企微、少数派、PixPin）和英文官方文档不一样：

- 默认红色；①②③ 画在图上
- 图上可以写短中文
- 正文用「如图所示 / 红框内」和图对上
- 云文档更爱裁弹窗；石墨、钉钉常不画框
- Dify 中文文档更像英文 SaaS：干净特写，偶尔一个红框

本 skill 站官方文档派的规矩（整窗、满对比、句子在 Markdown），手法菜单从两派都借。

## 十五种手法

| # | 手法 | 图上有什么 | 别人谁在用 |
|---|---|---|---|
| 1 | 方位总览 | 整窗 + 侧栏/顶栏/主区标签 | Azure 编号总览；Apple 引线标签 |
| 2 | 一图多编号 | 1–4 个框 + 角标 | ScreenSteps、企微、阿里云 |
| 3 | 一图一步 | 只标当前一下 | Tango / Scribe 默认 |
| 4 | 聚光变暗 | 四周压暗，目标亮 | Snagit Spotlight。GitHub 禁止 |
| 5 | 箭头指向 | 从空白指向目标；字不在箭头上 | ScreenSteps、ScreenGuide |
| 6 | 气泡短句 | 图上 ≤ 十来字 | Snagit Callout、PixPin |
| 7 | 局部放大 | 整窗 + loupe 连回原处 | PixPin / Snipaste |
| 8 | 点击热区 | 指针或涟漪 | Scribe、Camtasia。GitHub 不要指针 |
| 9 | 对错对照 | 左右：错的 / 对的 | 少数派；容易点错时 |
| 10 | 操作前后 | 左右同一窗，只改那一处 | Snagit 打码前后 |
| 11 | 步骤条 | 图顶「第 2 步 / 共 3 步」 | Snagit Step Capture |
| 12 | 打码 | 马赛克或占位 | 各家对外图 |
| 13 | 动线 | 编号 + 从 A 到 B 的路径 | ScreenSteps 侧栏→主区 |
| 14 | 介绍+图+图注 | 图外标题、图、下列表 | 教程页默认排版 |
| 15 | 单框 | 只一个描边，不编号 | GitHub 橙框、Mozilla 红框、华为「红框内」 |

出图一律 `scripts/compose.py --scene`（也可写在 marks.json 的 `"scene"`）。十五种对应：`overview` / `multi` / `one` / `spotlight` / `arrow` / `bubble` / `loupe` / `click` / `compare` / `before_after` / `banner` / `redact` / `path` / `caption` / `single`（另有 `leader` 引线）。名单：`compose.py --list-scenes`。`scripts/scenes.py` 只生成 Dify 样张，不是日常工具。坐标一律先量。

## 本 skill 的规矩

1. **整窗。** 产品窗口全在。去掉别人的桌面、其它 App。浏览器只留这一页。
2. **一图 1–4 个。** 再多拆第二张整窗。硬上限 6，不要硬塞。编号顺序 = 正文顺序。
3. **框贴控件，字边留一指缝。** 黄铜描边 + 角上编号。默认图上不写句子。一指缝 = `locate.py --pad` 默认 12 图像像素（2x 约 6 CSS 像素），不要再手扩一圈。贴死看不清，空一大圈又像圈错了控件。
4. **图上写字用引线。** 小框放空白（侧栏、页眉、图外一圈），细线指控件。Apple Preview / Tango。不准把字贴在控件堆上挡住上面或旁边的按钮。
5. **不要默认变暗。** 对比度和界面本身一样。
6. **徽章按整图缩放。** 3840 宽的窗缩进文档后，编号仍要能认。
7. **先量后画。** 目测会偏。

## 代币

| 名 | Hex | 用处 |
|---|---|---|
| plate | `#12151C` | 整窗外一圈台 |
| rule | `#2A3038` | 照片描边 |
| brass | `#D4A24A` | 框和编号（唯一强调色） |
| ink | `#12151C` | 编号数字 |
| ring | `#FFFFFF` | 编号外圈 |
| crimson | `#C43630` | 只用于「错」对照 |
| ok | `#2E7D50` | 只用于「对」对照 |

红框仅在用户要「红框内」那种云文档句式时用 `#F71701`。不要和黄铜混在同一张图。

## 禁止

- 把控件裁成「只有这一条」的特写（读者不知道在哪）
- 彩虹框、无编号的一堆箭头、图内长句
- **标签 / 气泡压住其它按钮、菜单项、输入框**（字和框之间至少留出引线空隙）
- **框线贴着字，或反过来空一大圈**（留一指缝即可）
- 整桌面壁纸、通知、其它窗口
- 对着 PNG 估或手改 x/y
- 一张图把十五种手法叠满
